Service status and limitations

The honest version. Last updated: 25 September 2026.

Current status #

This page cannot show live status. To check whether the API is up right now, call /healthz: it returns HTTP 200 with a small JSON body when the application process is up. It does not check the database or the inbound mail server.

This page is served by the application it describes: if MailMint is down, this page is down too.

Deployment #

The application, its PostgreSQL database and the inbound mail server run on one single server in Finland (EU), rented from Hetzner Online GmbH — the same hosting described in the privacy policy.

The consequences: there is no redundancy and no automatic failover to another region. Maintenance or a server fault means downtime.

TLS #

The website and API are served over HTTPS. Inbound mail on mx.smooth-operator.online port 25 offers STARTTLS with a certificate for mx.smooth-operator.online issued by Let's Encrypt, so senders that verify certificates can deliver over encrypted connections.

Service level #

MailMint is provided as is. There is no service level agreement, no guaranteed uptime, and no uptime percentage is published. See the terms of service.
